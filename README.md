#How to run Calculator.go

The method I use to run this file would be as follows:

Once downloaded go open the CICD_Pipeline_1 folder. I personally use Windows so next to the search bar there is a second bar that has something along the lines of C:\Users\...\...\Documents\CYSE6225\CICD_Pipeline_1.

Where it shows the path of the folders I replace it with CMD to open the command line.
I do this in order to open the go files without having to look for the folder pathway. Once the Command line is open I use go run . in order to run the calculator.go file. Once it opens you will be prompted to choose one of 4 options: 1. Addition 2. Subtraction 3. Division or 4. Multiplication. Inputting the assigned number will prompt you to choosing two numbers to add, subtract, divide, or multiply.

Once the two numbers are chosen such as 1 and 2 they will be plugged into the selected formula giving you the answer. 

run go test . in order to run the needed unit tests for Calculator.go
